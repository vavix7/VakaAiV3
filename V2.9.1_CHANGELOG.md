# Vaka V2.9.1

- Added daily Free Fire profile synchronization.
- Members who are confirmed by the API to have left the configured guild are notified, removed from the Telegram guild chat, and deleted from the players table.
- Guild/KV rules are now sent as the configured image only; the old menu message is removed when possible.
- KV proposal rejection now sends a private notification to the proposer.
- Existing application approval/decline private notifications are preserved.
- Existing RP, moderation, shop, access, training and backup functionality preserved.
