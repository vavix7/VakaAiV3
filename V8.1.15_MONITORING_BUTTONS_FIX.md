# V8.1.15 — monitoring/import and panel stability fix

- Fixed `menu_stats` / activity panel crash when a legacy week row has no matching `players` record.
- Fixed the analogous lifetime rank lookup used by the rewards/statistics view.
- Added `VAKA_ACTIVITY_LIST` import for authorized activity admins in any chat.
- Accepts both `VAKA_ACTIVITY_LIST` and Markdown-escaped `VAKA\_ACTIVITY\_LIST`.
- Activity import uses UID as the identity; only players already present in the database are accepted.
- Imported nicknames are replaced by the canonical nickname from the database.
- Unknown UIDs are reported and are never registered by monitoring.
- Repeated imports update the open week's snapshot.
- Week rollover/cutoff is Monday 04:00 Moscow time.
- Existing commands, callback routes, panels, and database files are preserved.
