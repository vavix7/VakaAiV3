# Vaka V8.1.12

Telegram-бот для гильдии Free Fire с сохранением существующей системы активности, SQLite-базы, модерации, коинов, турниров, достижений, КВ и панелей.

## Запуск

1. Создай виртуальное окружение.
2. Установи зависимости: `python -m pip install -r requirements.txt`.
3. Скопируй `.env.example` в `.env`.
4. Заполни `BOT_TOKEN`, `FF_API_KEY` и `AI_API_KEY` при необходимости.
5. Запусти `python bot.py`.

## SiamBhau Premium API

Основной Free Fire API: `https://siambhau69.eu.cc`.

- `FF_API_PROVIDER=siambhau`
- `FF_API_BASE=https://siambhau69.eu.cc`
- `FF_REGION=RU` (по умолчанию; вывод региона в /ff всегда: 🇷🇺 Россия)
- Регион запроса берётся из `FF_REGION`; для /ff отображается 🇷🇺 Россия по требованию владельца.
- API-ключ хранится только в `.env`.

`/ff UID` получает полный профиль через `/freefireinfo/bhau`, затем получает BR/CS статистику, Ban Check и PNG-баннер через `/banner/profile`.

Дополнительные команды:

- `/ffstats UID [br|cs]`
- `/guildinfo [CLAN_ID]`
- `/bancheck UID`
- `/ffapi`

## КВ

Предложение КВ проходит FSM-форму. Администратор ранга 4+ должен одобрить предложение. После одобрения Vaka публикует в `GUILD_CHAT_ID` название гильдии противника, составы, дату/время и назначение.

## Активность

- Данные мониторинга принимаются только из `MONITORING_CHAT_ID`.
- Поддерживается строгий протокол `VAKA_MONITORING_V1`.
- Также бот автоматически распознаёт обычный 5-колоночный список: `name/ID | Акт неделя | Акт всего | тур Акт | тур Всего`.
- Пример строки: `Vavix m? 3829 39000 260 780`.
- Если в строке указан ник, он сопоставляется с игроком в базе; UID можно указывать напрямую.
- В недельный снимок записывается только `Акт неделя`; остальные числа не увеличивают lifetime и коины.
- В течение недели изменяется недельное значение.
- В понедельник в 04:10 МСК закрывается предыдущая неделя.
- Rollover защищён от повторного начисления.
- Lifetime-активность не изменяется обычным обновлением API-профиля.

### Google Drive OAuth

- OAuth JSON должен быть типа **Desktop app / Installed application**.
- По умолчанию Vaka использует `credentials.json` рядом с `bot.py`.
- Старое имя `google_credentials.json` поддерживается как fallback, если `credentials.json` отсутствует.
- OAuth токен сохраняется в `token.json`. Этот файл не должен попадать в публичный ZIP/репозиторий.
- Кнопка `☁️ Google Drive` в панели резервных копий открывает список облачных копий и позволяет отправить последнюю локальную копию.
